Anesthculator v0.41

Drug Library:
- Every dose record now has a visible 💧 Dilution button.
- Dilution opens the existing calculator using THAT dose record's dose/unit/stock rather than only the generic drug.
- Target concentration and final volume are remembered locally per drug + phase + indication.
- Custom stock overrides are respected.

LOCAL drug CRUD:
- ✏️ Edit and 🗑 Delete are now displayed directly in each LOCAL dose-record card.
- They are no longer only associated with the top of the generic Drug Card.
- Delete confirmation still identifies the selected drug and refreshes immediately.

Existing Cloud evidence/verification controls, Back behavior, category fixes, and TBW/IBW/LBW/AdjBW features are preserved.
