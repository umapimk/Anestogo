ℹ️ Library guide / verification status
Search and Category are mutually exclusive: typing a drug name resets Category to All; choosing a Category clears the old search automatically. Hidden drugs remain searchable and are marked HIDDEN. Library Hide does not affect Plan.
Category integrity: Primary Category is checked by Generic name against the Master Medication Database, so opioid drugs cannot be mislabeled as Non-Opioid Analgesics.
Classification: a single canonical set of 16 Primary Categories is used; legacy synonyms are migrated to the canonical category.
Verification: SOURCE VERIFIED = authoritative source checked; LOCAL VERIFIED = locally/institution-verified dose record; THAI CROSS-CHECK PENDING = Thai-primary reconciliation incomplete; CONFLICT = sources differ; DOSE LOCKED = calculator disabled for that record.

v0.25 Canonical Drug Categories

Category names are standardized to the 16 Primary Categories in ยา ค้นจาก ai(2).xlsx.

Synonymous legacy categories are automatically merged. Example: Opioids + Analgesics / Opioids + Opioid Analgesics → Opioid Analgesics. Sub Category remains the Drug class and is not promoted into a separate Primary Category.
v0.24 Drug Classification

Primary Category และ Drug class ถูกจัดใหม่จากไฟล์ ยา ค้นจาก ai(1).xlsx เป็นหลัก

Mapped 63 generic-name records in the built-in library. Classification metadata does not change dose-verification status. User Local Classification Overrides still take precedence until Reset to Reference.
v0.32 Local Verification

Local Verify is restored and is now dose-record specific: one drug can have separate local verification for Induction, Maintenance, Post-op, RSI, infusion, or any other indication/phase.

Required fields: dose min/default/max, unit, stock, route/population, traceable reference, version/date, and page/table/section. Local Verify is stored in this browser/device and does not overwrite the built-in source record.
v0.31 Stock Concentration Override

Stock concentration edits are now persistent per drug on this browser/device and are applied immediately to dose-to-mL and dilution calculations.

Use Edit stock on the drug card or dosing record. Reset default restores the built-in/reference stock value. Clinical dose logic is otherwise unchanged.
v0.28 Category Integrity

Generic-name category integrity is enforced using the uploaded Master Medication Database.

Examples: Fentanyl, Morphine, Remifentanil, Sufentanil, Pethidine/Meperidine and Hydromorphone are forced to primary category Opioid Analgesics. Paracetamol, Parecoxib and Ketorolac remain Non-Opioid Analgesics & Co-analgesics. Legacy contradictory browser overrides are automatically cleaned on first load.
v0.23 Verification Batch 1

Source-level verification completed for Propofol induction, Etomidate induction, Rocuronium intubation/RSI/maintenance/infusion, Neostigmine reversal, Lidocaine adult maximums, Bupivacaine adult technique-specific limits, Ropivacaine adult technique-specific tables, RCAT/MHAUS dantrolene crisis source, and ASRA LAST lipid-emulsion source.

Thai indication-level cross-check remains pending where an authoritative Thai source has not yet been reconciled. Remaining Drug Library entries stay VERIFY or DOSE LOCKED.
