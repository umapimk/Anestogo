Anesthculator v0.55 — Controlled Clinical Evidence Workflow

Includes v0.52–v0.55:
- Table-aware parsing using PDF coordinates.
- Smart phase detection for induction/RSI, maintenance/infusion, sedation, emergency and reversal.
- Conflict resolver for incompatible units, weight bases, phases and materially different ranges.
- Clinician review queue with explicit individual or bulk approval.
- Bulk approval is limited to mapped Cloud dose records with confidence >=80% and no detected conflict.
- Every approved change writes verification history.
- Evidence never changes medication data automatically.
- Built-in/local matches are comparison aids only; Cloud mapping and explicit clinician approval remain mandatory.

No SQL migration is required.
