Anesthculator v0.42 — Drug Lifecycle Management

- Active / Archived tabs in Drug Library.
- Archive removes drug from Active Library and Plan but preserves reference/verification history.
- Restore brings it back.
- Search can search current view or Active + Archived.
- Archive/Restore buttons appear inside each dose-record card.
- Permanent Delete remains available only for Local/Custom drugs.
- Cloud archive uses existing drugs.active field; no SQL migration required.
