# Deploy v0.72 to GitHub Pages

1. Back up the current repository.
2. Delete the old deployed files or upload this release so the root contains `index.html`, `app.js`, `style.css`, `senior-mentor.js`, `clinical-reasoning.js`, and `sw.js`.
3. Do not upload the enclosing ZIP folder as an extra nested directory.
4. Commit to the branch used by GitHub Pages.
5. After deployment, open the Pages URL, not the repository README page.
6. On iPhone, if an old version remains: Settings → Safari → Advanced → Website Data → remove the GitHub Pages domain, then reopen it. The v0.72 service-worker cache name is also new.
